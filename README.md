# デバイス定期メンテナンス計画表

PC・スマートフォンのセキュリティと安定性を保つための、**必要最小限の定期メンテナンス手順**をまとめたリポジトリです。
項目が多いと確認する頻度そのものが減ってしまうため、各デバイスの項目は10項目以内に絞っています。

---

| デバイス | ドキュメント | 特徴 |
| :--- | :--- | :--- |

## 🗂️ 各ドキュメントの構成

| 区分 | 内容 |
| :--- | :--- |
| **📅 月1回** | OS・アプリの更新、ウイルスチェック、バックアップ確認など、毎月確認する項目。 |
| **⏳ 数ヶ月に1回** | システム点検、ディスク確認、不要データの整理など、たまに行う項目。 |
| **🔘 オプション** | 初回設定時、または不具合があったときだけ行う項目。 |

## 💡 方針
- **コマンドで済むものはコマンドで集約**：Windows・macOSは、画面操作の手間を減らすため、コマンドをまとめて貼り付けて実行できるようにしています。
- **効果の薄い項目は載せない**：確認しても対応が発生しない項目（ストレージ空き容量やバッテリー状態の確認など）は省いています。
- **非公式のクリーナー・高速化アプリは使わない**：標準機能だけで十分な状態を保てます。
